# Настройка публикации на GitHub Pages

Это руководство объясняет, как включить и настроить GitHub Pages для этого репозитория.

## Обзор

Репозиторий включает рабочий процесс GitHub Actions (`.github/workflows/deploy.yml`), который автоматически собирает и развертывает веб-интерфейс на GitHub Pages при каждом пуше в ветку `main`.

## Необходимые права

- Права администратора репозитория для настройки GitHub Pages
- Рабочий процесс должен находиться в ветке `main`

## Включение GitHub Pages

Следуйте этим шагам для включения GitHub Pages:

### 1. Перейдите в настройки репозитория

1. Откройте ваш репозиторий на GitHub
2. Нажмите на вкладку **Settings** (Настройки)
3. В левой боковой панели нажмите на **Pages** (в разделе "Code and automation")

### 2. Настройте источник GitHub Pages

1. В разделе **Build and deployment** найдите секцию **Source**
2. Выберите **GitHub Actions** из выпадающего списка
3. Нажмите **Save** (если кнопка появится)

### 3. Запустите рабочий процесс

Рабочий процесс автоматически запустится когда:
- Код будет отправлен в ветку `main`
- Вы запустите его вручную через вкладку Actions

Для ручного запуска:
1. Перейдите на вкладку **Actions**
2. Нажмите на рабочий процесс **Deploy to GitHub Pages**
3. Нажмите кнопку **Run workflow**
4. Выберите ветку `main`
5. Нажмите **Run workflow**

## Проверка развертывания

После успешного выполнения рабочего процесса:

1. Перейдите на вкладку **Actions** для проверки статуса
2. После завершения развертывания ваш сайт будет доступен по адресу:
   ```
   https://<username>.github.io/chatgpt-subtitle-translator/
   ```
   Замените `<username>` на ваше имя пользователя или организации GitHub

3. Вы также можете найти URL в:
   - Настройки репозитория → Pages (под "Your site is live at...")
   - В деталях выполнения рабочего процесса

## Структура рабочего процесса

Рабочий процесс состоит из двух задач:

### Задача сборки (Build)
- Проверяет репозиторий
- Настраивает Node.js 22
- Устанавливает зависимости с кешированием npm
- Собирает приложение Next.js в режиме статического экспорта
- Загружает артефакты сборки

### Задача развертывания (Deploy)
- Развертывает артефакты на GitHub Pages
- Создает окружение развертывания `github-pages`
- Предоставляет URL развертывания

## Решение проблем

### Рабочий процесс не появляется
- Убедитесь, что файл процесса находится в ветке `main`
- Проверьте, что файл расположен по пути `.github/workflows/deploy.yml`

### Ошибки сборки
- Проверьте логи процесса на вкладке Actions
- Убедитесь, что все зависимости правильно указаны в `web/package.json`
- Проверьте конфигурацию Next.js в `web/next.config.js`

### Ошибки развертывания
- Убедитесь, что GitHub Pages включен в настройках репозитория
- Проверьте, что процесс имеет правильные разрешения
- Убедитесь, что источник установлен на "GitHub Actions" (не "Deploy from a branch")

### Ошибки 404 после развертывания
- Проверьте, что `basePath` в `web/next.config.js` соответствует имени вашего репозитория
- Убедитесь, что все внутренние ссылки используют правильный базовый путь

## Конфигурационные файлы

Ключевые файлы для развертывания на GitHub Pages:

- `.github/workflows/deploy.yml` - рабочий процесс GitHub Actions
- `web/next.config.js` - конфигурация Next.js с basePath
- `web/package.json` - зависимости и скрипты сборки
